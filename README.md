# Тус по Репосту — единый бот предложки и админ-панели

## Возможности
- Одно приветствие для пользователей.
- Приём текста, фото, видео, документов и голосовых сообщений.
- Явное уведомление о том, какие данные отправителя сохраняются.
- Админ-панель внутри того же бота.
- Добавление и удаление администраторов через меню (только владелец).
- Добавление нескольких каналов через меню, проверка прав бота и выбор основного канала.
- Одобрение/публикация, отклонение, история отправителя, статистика, чёрный список.
- SQLite хранит администраторов, каналы, обращения, согласия и блокировки.

## Переменные окружения
Требуются только:
- `BOT_TOKEN` — токен от @BotFather.
- `OWNER_ID` — числовой Telegram ID владельца.
- `DB_PATH` — путь к SQLite, по умолчанию `tus_po_repostu.sqlite3`.

## Установка
1. Создай бота через @BotFather.
2. Заполни `.env` по примеру `.env.example` (или добавь эти переменные в Environment Variables хостинга).
3. Установи зависимости: `pip install -r requirements.txt`.
4. Запусти `python bot.py`.
5. Открой бота и отправь `/admin`.
6. В админ-панели открой «Настройки» → «Каналы». До добавления канала выдай боту статус администратора с правом публикации.
7. Открой «Настройки» → «Администраторы» и добавь модераторов по числовому Telegram ID.

## Важное
- Владелец определяется только переменной `OWNER_ID`; его нельзя удалить через меню.
- Только владелец может добавлять/удалять администраторов и каналы, а также менять основной канал.
- Модераторы могут просматривать и обрабатывать предложки, но не управляют настройками.
- Пользователь должен сначала нажать «Отправить предложку» и подтвердить уведомление о данных. Бот не может раскрыть автора, который написал через чужого стороннего бота.
- Для публикации бот должен быть администратором выбранного канала с правом публикации сообщений.
- Рекомендуется настроить резервное копирование SQLite и понятную политику конфиденциальности.

## Запуск
Команда запуска: `python bot.py`
